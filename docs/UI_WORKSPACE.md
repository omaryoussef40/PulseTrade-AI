# Trading workspace

The sidebar has seven destinations. Older Scanner, Daily Stock Levels, Account,
Logs, Earnings and AI Audit links resolve to their new workspaces.

| Page | Contents |
| --- | --- |
| Overview | Latest account snapshot, tracked exposure, strategy status and setup issues |
| Strategies | PMB, Daily Stocks and shared Capital Allocation |
| Live Trading | Positions, Approvals, Orders and Controls |
| Backtesting | Historical tests, live-settings copy, comparison and saved results |
| Trade Journal | Performance and AI Audit |
| Market Research | News and intelligence, Earnings and Price Action Lab |
| Settings | Connection, Integrations, Display/reporting preferences and Logs |

PMB has Scanner, Charts and Setup views. Setup separates signals, risk/exits,
watchlist and schedule. Daily Stocks has Scanner, Charts, Setup and Daily Plan;
Daily Plan accepts pasted Pine or a reviewed email brief. Mailbox configuration
belongs in Settings → Integrations.

Capital Allocation manages strategy participation and the account split. Stock
position/risk/ticker limits belong in Daily Stocks → Setup. Global account mode,
automation and order permissions, plus the separate stock execution approval,
belong in Live Trading → Controls.

Settings are saved explicitly. Opening a screen does not save its defaults.
Saving one settings section preserves changes made elsewhere. Saving a daily
plan leaves execution permissions intact. Unsaved Pine drafts survive switching
between the plan and chart views.

Backtesting copies live PMB settings into a draft. Saving backtest settings does
not change the live watchlist or risk configuration. Applying tested settings to
the engine remains an explicit, confirmed action inside a collapsed section.
Saved run metadata retains the simulator's existing settings snapshot.

The fixed bottom status bar shows account mode, IBKR connection, automation and
New York time. It tracks the measured main area and sidebar width when the menu
opens, closes or is resized. Page padding reserves its measured height, including
on narrow screens. The moving premarket watchlist appears only in Market Research. Position
rows distinguish PMB, Daily Stocks and other/manual holdings; broker marks are
read-only. Missing prices and P&L remain blank, and unresolved stock intents
retain their status labels. Existing exit and order approval controls remain in
force.
